# 🤖 AI Agent Hub

Централизованное хранилище документации, планов и кода для локального AI-агента на базе MCP-сервера и llama.cpp.

## 🎯 О проекте

Этот репозиторий содержит:
- **Документацию** по всем активным проектам AI-агента
- **Дорожную карту** развития (Roadmap)
- **Планы реализации** новых функций (Mirage, Ouroboros)
- **Список источников вдохновения** (REFERENCES.md)

Агент работает локально, без облака, на собственном железе. Все данные остаются на твоём компьютере.

##  Быстрый старт

### Запуск MCP-сервера
```bash
cd D:\AI_Servers\Agent
python mcp_server.py
```

### Запуск Tech Monitor (PyQt5)
```bash
cd workspace/tech-info
.venv\Scripts\activate
python main.py
```

## 🛠️ Технологии

- **Python 3.10+** — основной язык
- **llama.cpp** — локальный запуск LLM (Ornith-1.5 9B Q8_0)
- **MCP Protocol** — протокол взаимодействия агента с инструментами
- **PyQt5** — GUI для десктопных приложений
- **Gitea** — локальный Git-сервер для хранения кода и документации
