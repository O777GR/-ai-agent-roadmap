# 📚 Источники вдохновения и референсы

Этот проект вдохновлён работами замечательных разработчиков и исследовательских групп. Ниже приведены репозитории, которые легли в основу архитектуры и идей AI Agent Hub.

## 🏗️ Архитектура и песочницы

### **Mirage** — Виртуальный терминал для AI-агентов
🔗 [strukto-ai/mirage](https://github.com/strukto-ai/mirage)
- **Что взяли:** Архитектура виртуальной файловой системы (VFS), изолированных сред выполнения и детального контроля доступа.
- **Наша реализация:** План Mirage Lite.

## 🧠 Память и самообучение

### **ReMe** — Саморазвивающаяся база знаний
🔗 [agentscope-ai/ReMe](https://github.com/agentscope-ai/ReMe)
- **Что взяли:** Концепция локальной, эволюционирующей персональной базы знаний для агентов.
- **Наша реализация:** Проект VeKnora в ROADMAP.md.

### **mem9** — Постоянная память с визуализацией
🔗 [mem9-ai/mem9](https://github.com/mem9-ai/mem9)
- **Что взяли:** Гибридный вызов памяти, общая память для мульти-агентных систем, визуальная панель мониторинга.
- **Наша реализация:** Планируется в VeKnora.

### **Ouroboros** — Агентная ОС для самосовершенствования
🔗 [Q00/ouroboros](https://github.com/Q00/ouroboros)
- **Что взяли:** Цикл "выполни → проанализируй ошибку → обнови инструкции → повтори" без жёстких контрактов оценки.
- **Наша реализация:** Ouroboros Loop (Фаза 1 реализована).

## 🛡️ Безопасность и валидация

### **Aegis** — Надёжность AI-программирования
🔗 [ganyuanran/aegis](https://github.com/ganyuanran/aegis)
- **Что взяли:** Методы pre-execution validation, проверка кода перед выполнением, снижение количества переделок.
- **Наша реализация:** Планируется в Ouroboros и Mirage.

## 🌐 Веб-автоматизация и браузеры

### **BrowserSkill (Tencent)** — Подключение агентов к браузеру
🔗 [Tencent/BrowserSkill](https://github.com/Tencent/BrowserSkill)
- **Что взяли:** Концепция подключения AI-агентов к уже зарегистрированному браузеру через CDP.
- **Наша реализация:** Планируется как инструмент MCP.

### **Browser4** — AI-браузерный движок
🔗 [platona/Browser4](https://github.com/platona/Browser4)
- **Что взяли:** Идеи автономных агентов для веб-автоматизации и извлечения данных.
- **Наша реализация:** Рассматривается как альтернатива BrowserSkill.

## 📦 Библиотеки навыков

### **Skill Store** — Готовые навыки для AI-агентов
🔗 [unbeame/skill-store](https://github.com/unbeame/skill-store)
- **Что взяли:** Структурированный набор навыков в области обработки документов, программирования, ML и автоматизации.
- **Наша реализация:** Планируется как источник для VeKnora.

## 🎨 UI и рендеринг

### **Archify** — Детерминированный рендеринг UI
🔗 [tt-ai/archify](https://github.com/tt-ai/archify)
- **Что взяли:** Концепция генерации типизированного JSON IR вместо сырого HTML/кода, детерминированная компиляция в HTML/SVG.
- **Наша реализация:** Планируется в разделе стандартов кода.

##  Управление задачами

### **Dashi Taskboard** — Рабочая доска для Codex
🔗 [chuspeeism/dashi-taskboard](https://github.com/chuspeeism/dashi-taskboard)
- **Что взяли:** Концепция локальной панели управления с HTTP API для интеграции.
- **Наша реализация:** Gitea Projects (встроено).

## 🚀 Расширенная агентная экосистема (Новые находки)

### Песочница и Рантайм (Mirage)

- 🔗 [GCWing/BitFun](https://github.com/GCWing/BitFun) — Концепция запуска задач агента как изолированных мини-приложений.

### Самообучение и QA (Ouroboros)
- 🔗 [vostride/agent-qa](https://github.com/vostride/agent-qa) — Готовая архитектура самосовершенствующегося контроля качества кода агентом с использованием памяти.

### Память и Контекст (VeKnora)
- 🔗 [mindscale-noah/MindMemOS](https://github.com/mindscale-noah/MindMemOS) — Управление контекстом между агентами, автоматическая отработка навыков и интеграция с файловыми системами знаний.

### Зрение и Веб-автоматизация
- 🔗 [Anionex/dsh-vision-toolkit](https://github.com/Anionex/dsh-vision-toolkit) — Vision-инструменты для агентов: анализ скриншотов, распознавание GUI и визуальные задачи.
- 🔗 [chainbase-labs/Agentkey](https://github.com/chainbase-labs/Agentkey) — Мгновенный доступ агента к чтению веб-страниц и соцсетей без сложной настройки.

### MCP и Инструменты
- 🔗 [xyTom/coding-tools-mcp](https://github.com/xyTom/coding-tools-mcp) — Библиотека готовых MCP-инструментов для задач программирования и рефакторинга.

### Рабочие пространства и No-Code
- 🔗 [freestylefly/wesight](https://github.com/freestylefly/wesight) — Концепция рабочего пространства для локальных кодинг-агентов.
- 🔗 [fufankeji/deepseek-harness-studio](https://github.com/fufankeji/deepseek-harness-studio) — No-code студия для визуального улучшения и управления локальными моделями.

## 🧠 Графы знаний и управление навыками (Новейшие находки)

### **Memtrace**
🔗 [Memtrace](https://github.com/memtrace/memtrace)
- **Что взяли:** Концепция превращения кодовой базы в живой граф знаний (функции, классы, связи вызовов). Мгновенный запрос структуры кода без перечитывания файлов. Идеальный референс для VeKnora и OpenViking.

### **SkillCorpus**
🔗 [SkillCorpus](https://github.com/skillcorpus/skillcorpus)
- **Что взяли:** Механизм объединения источников, проверки лицензий, оценки качества и динамического подбора навыков под задачу. Основа для модуля импорта в VeKnora.
