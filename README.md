# 🤖 AI Agent Hub — Центр локального ИИ-агента

Централизованное хранилище документации, планов и кода для полностью локального AI-агента на базе MCP-сервера и `llama.cpp`. 

**Главный принцип:** 100% локально, без облака, на собственном железе. Все данные, память и код остаются на твоём компьютере.

## 🎯 О проекте

Этот репозиторий содержит:
- **Ядро агента:** MCP-сервер с 20+ инструментами для управления файлами, выполнения кода и работы с памятью.
- **Систему самообучения (Ouroboros):** Автоматический перехват ошибок и сохранение решений в базу знаний (`memory_bad.md`).
- **Оптимизацию контекста:** Встроенный лёгкий `context-mode` для поиска по коду без перегрузки контекстного окна.
- **Дорожную карту** развития и планы реализации новых функций.

## 🚀 Быстрый старт

### 1. Запуск MCP-сервера (Ядро)
Открой терминал и запусти сервер инструментов:
```bash
cd D:\AI_Servers\Agent
python mcp_server.py
```
*(Сервер будет слушать порт 8090)*

### 2. Запуск Tech Monitor (v3 CustomTkinter)
В **новом** терминале запусти актуальную версию системного монитора:
```bash
cd D:\AI_Servers\Agent\workspace\sys-monitor-v3-CustomTkinter
.\.venv\Scripts\activate
python main.py
```

## 🛠️ Технологический стек

- **Язык:** Python 3.10+ (строгая типизация, PEP 8, docstrings).
- **LLM:** `llama.cpp` (текущая: Ornith-1.5 9B Q8_0, на тестировании: GLM-5.3 GGUF).
- **Протокол:** MCP (Model Context Protocol) для связи LLM и инструментов.
- **GUI (исследуемые):** CustomTkinter (приоритет), Pygame, PyQt5 (отклонён из-за сложности).
- **Системные библиотеки:** `psutil`, `pygetwindow`, `Pillow`.
- **Хранение:** Локальный Git (Gitea), Markdown-файлы, SQLite (планируется).
