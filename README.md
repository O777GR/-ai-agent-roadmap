# 🤖 AI Agent Hub — Центр локального ИИ-агента

Централизованная, модульная платформа для полностью локального ИИ-агента на базе **MCP-сервера**, **llama.cpp** и **веб-интерфейса AI Studio**.

**Главный принцип:** 100% локально, без облака, на собственном железе. Все данные, память, код и процессы остаются строго на вашем компьютере.

---

## 🎯 О проекте

Этот репозиторий содержит полноценную экосистему для автономной работы ИИ-агента:

- **Ядро агента:** MCP-сервер с инструментами для управления файлами, выполнения кода и работы с памятью.
- **Мульти-агентная система:** 4 специализированные роли (Диспетчер, Инженер, Ревьюер, Библиотекарь) с динамической загрузкой промптов.
- **Веб-интерфейс AI Studio:** Современный UI на React/Vite с экспортом/импортом, управлением чатами и проектами.
- **Query Rewriter & Proxy:** Умная маршрутизация запросов и проксирование через `monitor.py`.
- **Безопасность:** Двухуровневый `SandboxManager` с жестким аудитом действий.
- **Система самообучения (Ouroboros):** Автоматический перехват ошибок и сохранение решений в локальной базе знаний.

## ⚡ Быстрый старт

### 1. Запуск LLM-сервера (llama.cpp)
```bash
# Запустите сервер на порту 8080 (пример с моделью Qwen)
llama-server.exe -m models\Qwen3.5-9B-Uncensored-HauhanCS-Aggressive-Q8_0.gguf --port 8080 -c 28160
```

### 2. Запуск MCP-сервера (Ядро агента)
```bash
cd D:\AI_Servers\ai-studio\agent_core
.venv\Scripts\activate
python main.py
# Сервер будет прослушивать порт 8090
```

### 3. Запуск Monitor + Rewriter (Прокси и маршрутизация)
```bash
cd D:\AI_Servers\ai-studio
.venv\Scripts\activate
python monitor.py
# Проксирует запросы к llama.cpp (порт 8080), добавляя логику роутинга. Порт: 8081
```

### 4. Запуск AI Studio (Веб-интерфейс)
```bash
cd D:\AI_Servers\ai-studio
npm run dev
# Откройте http://localhost:5173 в браузере
```

## 🛡️ Ключевые архитектурные особенности

- **SandboxManager (Двухуровневая защита):** 
  - *Жесткая граница:* Агент физически не может читать/писать файлы за пределами `D:\Workspaces`.
  - *Мягкая граница:* В рамках задачи агент ограничен папкой конкретного чата/проекта.
  - *Аудит:* Каждое действие записывается в `audit_log.jsonl`.
- **Ouroboros Loop (Самообучение):** При ошибке выполнения (`stderr` от `run_python_script`) агент анализирует причину, формулирует правило и сохраняет его в `workspace/.ouroboros/lessons.md`, чтобы не повторять ошибку в будущем.
- **Monitor Proxy:** `monitor.py` выступает умным шлюзом: он не просто пересылает запросы к `llama-server`, но и может перехватывать их для предобработки, оценки токенов или маршрутизации.

## 🛠️ Технологический стек

- **Backend / Ядро:** Python 3.10+ (строгая типизация, PEP 8, MCP Protocol)
- **Frontend:** React 18 + TypeScript + Vite + TailwindCSS
- **LLM Inference:** `llama.cpp` (локальные GGUF модели, например Qwen 2.5/3.x)
- **Мониторинг:** FastAPI + `psutil` + `httpx`
- **Хранение:** `localStorage` (чаты), Markdown (память/промпты), JSONL (аудит), SQLite (будущий RAG/Zeal)
